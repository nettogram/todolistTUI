# todolistTUI (v0)

A small C based to do list project as a CRUD application programming exercise

The current version (v0) is a CLI-based task manager with file persistence. v1 will wrap the basic logic in an ncurses TUI

# Features
- Add tasks to numbered slots (0-9)
- Prevents duplicate task slots
- Remove tasks
- Saves tasks using a text file
- Loads saved tasks back into runtime state
- Basic Makefile build

## Project Goals

This project is for practicing:

- C programming structure with modularity of source and header files 
- Function decomposition
- Pointer manipulation
- Basic Makefiles 
- Git/GitHub fundamentals
- File I/O with basic functions 
- Ncurses frontend / introductory library manipulation
